# Face Recognition Attendance Monitoring System

## Project Objective
Develop an AI-based Face Recognition Attendance Monitoring System that automatically identifies students and marks attendance using computer vision and machine learning.

## Technologies Used
- Python
- OpenCV
- InsightFace
- YOLO
- SQLite / CSV
- Flask

## Sprint Roadmap

### Sprint 0 - Environment Setup
Setup development environment and required tools.

### Sprint 1 - Dataset Collection
Collect and organize student face datasets.

### Sprint 2 - Face Detection
Implement real-time face detection.

### Sprint 3 - Face Recognition
Implement face recognition and identification.

### Sprint 4 - Attendance Logging
Automatic attendance recording with timestamps.

### Sprint 5 - Centralised data base
Integrate attendance records with ERP/student database and can access with different devices.
