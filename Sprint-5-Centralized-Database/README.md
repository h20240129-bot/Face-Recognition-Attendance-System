# Sprint 5 - Centralized Database

Status: In Progress 

## Goal
Store attendance records in a centralized cloud database so that attendance can be viewed from any device.

## Current Problem
Attendance is currently stored locally and can only be accessed from the local system.

## Tasks
- Setup cloud database (Supabase/PostgreSQL)
- Create attendance table
- Connect Python attendance system to database
- Upload attendance records automatically
- Enable remote access to attendance data

## Deliverable
Attendance records available from any device through a centralized database.

## Future Outcome
Teachers and administrators can view attendance from laptops, mobile phones, and other devices using a web dashboard.
